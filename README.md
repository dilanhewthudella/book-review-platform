# Book Review Platform

Book Review Platform is a full-stack CRUD web application developed using Python and Django. The application allows users to browse books, search by title or author, view book details, and create, edit, and delete books and reviews.

Users can rate books from 1 to 5, write reviews, and view reviews submitted by other users. The application also supports book cover image uploads and featured books on the home page.

## Features

- Browse and view books
- Search books by title or author
- Add new books
- Edit existing books
- Delete books
- Upload book cover images
- Add book reviews
- Edit and delete reviews
- Rate books from 1–5
- Display average book ratings
- Featured books on the home page
- Form validation
- Responsive Bootstrap interface
- Django Admin interface
- SQLite database

## Technologies Used

- Python
- Django
- SQLite
